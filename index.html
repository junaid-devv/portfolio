Architecture Deep-Dive & FAQs

Front-end: Developed in Flutter utilizing Provider and Bloc patterns for state management, ensuring smooth 60 FPS UI transitions across both iOS and Android.

Backend & Storage: Integrated with Firebase Authentication for COMSATS university domain verification, and Cloud Firestore for sub-second synchronization of campus schedules, announcements, and peer resources.

Offline Caching Push Notifications Secure Auth GPA Engine

Dialog Pipeline: The agent receives incoming webhooks via the official WhatsApp Business Cloud API. Messages are processed through an NLP intent parser in Python that extracts user preferences (e.g., table reservation for 4, order burger combo without pickles).

Database & Operations: Orders and reservations are stored in MongoDB with automated status tracking. Restaurant managers receive instant alerts via a dedicated webhook dashboard.

Webhook Dispatcher Fuzzy Intent Match Dynamic Menu Engine

Game Engine & Physics: Built using Unity and C#, utilizing lightweight 2D Rigidbody physics with custom Raycast collision detection to prevent tunneling on high-velocity obstacles.

Mobile Touch Optimization: Custom touch gesture recognition script handles taps, directional swipes, and hold mechanics with zero touch latency, designed for low battery consumption on handheld devices.
